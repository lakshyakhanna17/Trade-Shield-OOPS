# TradeShield Development Instructions

1. Read README.md, PROJECT_REQUIREMENTS.md and docs/ before coding.
2. Follow the agreed technology stack.
3. Follow the supplied database schema.
4. Keep the backend modular. Do not put the entire application in one file.
5. Separate models, services, detection logic and API routes.
6. Demonstrate all four OOP pillars clearly.
7. Use reusable React components.
8. Do not hardcode fake fraud alerts as the detection engine.
9. All bot orders must pass through the trading engine.
10. Validate user input and handle errors properly.
11. Write tests for important business logic.
12. Never expose API keys in frontend code.
13. Keep frontend and backend connected through documented API endpoints.
14. Update documentation when implementation changes.
15. Do not claim features are complete until they have been tested.

Build in small stages. Explain the implementation before making major architectural changes. Ask for approval before moving to the next major stage.
